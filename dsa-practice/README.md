A structured, hands-on project to prepare for product-based company coding interviews.

## 🏁 Getting Started

1. **Open this project in IntelliJ IDEA**
2. **Start with Day 1:** Navigate to `phase1_foundation/day01_arrays/`
3. **Read the problem description** in the Javadoc comments
4. **Implement your solution** in the `YOUR CODE HERE` sections
5. **Run `main()`** to test your solution
6. **Check solutions** in the `solutions/` directory only after attempting
